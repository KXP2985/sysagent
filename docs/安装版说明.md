# SysAgent 正式安装版（setup）

## 安装

双击 `SysAgent-Installer.exe`：

1. 选择安装范围：**仅当前用户**（推荐，免管理员）或 **所有用户**（Program Files，需管理员）
2. 确认安装目录、是否开机自启
3. 完成后可直接启动，浏览器打开控制台 http://127.0.0.1:8765/

安装内容：

| 位置 | 内容 |
|------|------|
| 程序目录 | SysAgent.exe、控制台、启动.bat、卸载器 |
| 开始菜单 / 桌面 | 启动 SysAgent、控制台、卸载快捷方式 |
| 「应用和功能」/「程序和功能」 | SysAgent 智能运维体（可从系统卸载入口移除） |

**数据目录**（config/记忆/模型/日志）：

- 「仅当前用户」安装 → 程序目录内
- 「所有用户」安装 → `%APPDATA%\SysAgent`（Program Files 不可写，数据与程序分离）

## 静默安装（企业/脚本部署）

```bat
SysAgent-Installer.exe --silent --dir "D:\SysAgent" --autostart
SysAgent-Installer.exe --silent --all-users --dir "C:\Program Files\SysAgent"
```

## 卸载

开始菜单「卸载 SysAgent」、系统卸载入口，或：

```bat
SysAgent-Installer.exe --uninstall
```

会清理快捷方式、开机自启、卸载登记；程序目录与数据目录删除前会逐项询问（数据默认保留）。

## 构建（开发者）

```bash
.venv\Scripts\python scripts\build_installer.py
# 先自动构建便携版载荷，再产出 dist/SysAgent-Installer.exe
```

另有 `installer/setup.iss`：若本机装有 Inno Setup 6，可用 `ISCC.exe installer\setup.iss`
编译出传统向导样式的 `SysAgent-Setup.exe`（需管理员，数据固定在 `%APPDATA%\SysAgent`）。

## 说明

- 未签名 exe 可能被杀软误报，添加信任即可；
- Ollama 不随安装包分发，目标机器可自行安装 Ollama，或在「设置 → 模型管理」使用云端模型；
- 便携版（zip）、源码模式与本安装版可共存，数据互相独立。
