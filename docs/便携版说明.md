# SysAgent 便携版使用说明

## 快速开始

1. 解压 `SysAgent-Portable-win64.zip` 到任意目录（如 `D:\SysAgent`）
2. 双击 **`启动.bat`**
3. 浏览器会自动打开控制台 **http://127.0.0.1:8765/**
4. 停止服务：关闭标题为 `SysAgent Server` 的黑窗口

首次启动会在本目录自动创建：

| 目录/文件 | 作用 |
|-----------|------|
| `config.yaml` | 配置（监听项目、白名单、QQ、代码学习等） |
| `data\` | 记忆、模型配置、能力进化运行时 |
| `logs\` | 服务与项目日志 |

整个文件夹可以拷到 U 盘/其他电脑直接用，数据都跟着走。

## 模型

- 默认走 **本地 Ollama**（若已安装并 `ollama pull qwen2.5:7b`）；
- 没装 Ollama：在「设置 → 模型管理」添加云端模型（OpenAI 兼容）并设为默认即可。

## 常见问题

- **杀软提示**：未签名 exe 可能被误报，添加信任或选择「仍要运行」；
- **端口占用**：用命令行启动 `SysAgent.exe --port 8766`；
- **换目录**：直接剪切整个文件夹即可，路径无关；
- **重置**：删除 `config.yaml`、`data\`、`logs\` 后重新启动，会恢复初始状态。

## 与源码项目模式的关系

便携版是同一套代码的冻结产物。若你是开发者，仍可在项目目录用
`.venv\Scripts\python -m agentd` 以源码方式运行（见项目 README），两种方式互不干扰、
数据目录各自独立。
